# Literature targets for recursive-claim audit

Before promoting the recursive result into the manuscript, compare the exact claim against at least
these prior-work families:

1. Luenberger functional observers and reduced-order observers.
2. Moore and Ledwich-style minimum-order observers for linear functions of the state.
3. Darouach-style functional observability / functional observer existence conditions.
4. Exact state aggregation / lumping of linear stochastic systems.
5. Reduced-basis and reduced-order Kalman filtering.
6. Lossless linear sensor transformations for distributed estimation.
7. Extensions of lossless sensor transformation to cross-correlated measurement noise.
8. Goal-oriented Bayesian inference / posterior maps and data compression.

The novelty question is not whether a low-dimensional function of a linear state can be observed.
The narrower target is whether prior work already gives the same necessary-and-sufficient
correlated-noise-factor subspace, bounded by the recursively sufficient task-state dimension, while
retaining all observation rows and non-shared covariance terms and providing exact full-factor
fallback.
