# PointWorld--Flat'n'Fold claim and evidence map

This map prevents an infrastructure result from being promoted into a scientific
claim prematurely.

| Layer | Current evidence | Required positive evidence | Exact negative/stop outcome |
| --- | --- | --- | --- |
| Representation | Versioned sparse persistent-point contract and strict PointWorld converter | One frozen real source export with correct point, frame, action, and coordinate semantics | Retained representation-negative result; no dense rescue |
| Support | Executable three-camera garment inventory to `ProviderSupportFeasibilityV1` | Complete source/calibration/target roster and support-positive inventory before inference | Support-negative provider version |
| Provider mean/identity | Not tested | Garment-grouped source/calibration competence against persistence and raw PointWorld comparators | Stop or repair action/coordinate/identity path only |
| Native uncertainty | Raw PointWorld log variance retained but explicitly uncalibrated | Source/calibration-only proper-score, coverage, NEES, width, and dependence calibration | Keep simple/uniform estimator or exact fallback |
| Recursive Prob4D value | Existing MotionCrafter and controlled gauge evidence only | Held-out garment improvement over raw PointWorld and simple overlap without calibration regression | Retain simpler PointWorld/tree arm |
| BayesianPhysTwin value | Existing controlled mechanism and retrospective MotionCrafter boundary only | Frozen query improvement over physical fallback and raw PointWorld with bounded harmful accepted updates | Exact physical fallback; no downstream claim |
| Causal4D value | Separate frozen physical protocol | Separately sealed future study only | No Causal4D claim in this paper |

The intended eventual paper claim is conjunctive: a fresh action-conditioned
provider must be technically supported, competent enough to evaluate, improved
or made safer by the recursive belief, and useful for one frozen physical query.
No downstream layer may rescue failure of an upstream layer.
