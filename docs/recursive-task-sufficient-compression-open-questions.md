# Open questions

1. Can the fixed LTI closure be generalized to a finite-horizon time-varying backward recursion
   while retaining a useful minimum-space statement?
2. Can the observation-row requirement be weakened to an information-equivalent condition without
   collapsing into classical measurement compression?
3. Under which cross-time process/measurement noise correlations does the induction remain exact?
4. How should closure changes be handled under relinearization and robust reweighting?
5. Which public deformable-object sequence provides a genuinely changing downstream task family
   rather than another immutable-query benchmark?
6. Does the recursive task closure remain materially smaller than the physical state in a realistic
   deformable estimator, or does the observation map force full-state closure?

A negative answer to question 6 would substantially reduce the practical value of the recursive
extension and should be discovered before expanding the paper claim.
