# CUT3R depth-reprojected compatibility profile v1

This historical profile imports the ordinary CUT3R `depth/conf/camera` output by
reconstructing XYZ from depth and fitted intrinsics. It remains available through
[`cut3r-online-provider.md`](cut3r-online-provider.md) for frozen evidence and
compatibility.

New source qualification should preserve CUT3R's original direct XYZ prediction
through [`cut3r-direct-pointmap.md`](cut3r-direct-pointmap.md) and retain a
target-free geometry-fidelity and causal-prefix-closure report.
