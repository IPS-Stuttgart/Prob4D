# PokeFlex posterior-preserving compression: real-geometry diagnostic v1

Status: **requested on a known-incomplete local mirror**. This study is a
separately versioned diagnostic for the posterior-compression kernel in PR #342.
It does not continue, repair, retune, or open the previously retained Causal4D
PokeFlex target experiment.

## Question

On material-point trajectories taken from released real deformable-object data,
does the posterior-preserving shared-noise projection retain the complete local
Gaussian physical-query posterior while a generic equal-rank covariance-PCA
projection can change it?

The theorem itself is algebraic. Real data are used here to test the geometry,
numerical conditioning, retained rank, and storage behavior under trajectories
that were not generated by the controlled Gaussian simulator. This is not a
claim that the locally fitted Gaussian model is a calibrated PokeFlex predictor.

## Known data boundary

The requested root is `/mnt/lexar4tb/pokeflex`. It was reported to contain about
548 GiB in 170 ZIP archives, but the mirror is explicitly incomplete. The run
therefore never treats 170 as a completeness criterion. It records:

- every observed ZIP path and size;
- whether its central directory is readable;
- a central-directory digest over member name, uncompressed size, and CRC;
- the member suffix histogram;
- whether a supported geometry candidate exists; and
- every deep-read or parser failure.

Opening a central directory does not verify all compressed payload bytes. For the
deterministically selected bounded subset, geometry members are read through
Python's ZIP implementation, which checks their stored CRC. Raw archives are not
copied into the workflow artifact.

## Outcome-blind selection

Candidate geometry is limited to non-pickled numeric trajectories or sequences
of OBJ, PLY, XYZ, or PTS files with stable vertex count. Archive selection is the
ascending SHA-256 order of the relative archive path and candidate key. It does
not use query errors, covariance results, object labels, or target outcomes.
At most 24 archives and ten frames per selected archive are deeply read.

Variable vertex count fails closed because vertex correspondence is not invented.
Unsupported layouts remain in the inventory and produce a machine-readable
`not-evaluable` decision if no archive can be interpreted safely.

## Real-geometry local model

For each admitted trajectory, the first frame defines a deterministic set of 64
material vertex indices. The final selected frame is held out from construction
of the observation windows. Geometry is centered and normalized by the first
frame's bounding-box diagonal; the original extent is retained without asserting
a physical unit.

The shared factor is a cumulative Sim(3) gauge chain. Per-coordinate increment
scales are estimated from consecutive real prefix geometries and clipped only by
the protocol-fixed numerical floors and ceilings. The physical covariance factor
uses low-rank modes of the real prefix displacement trajectory plus three
translation modes. A deterministic extreme-principal-axis material patch defines
a three-dimensional endpoint-displacement query.

This is a stress model constructed from real geometry, not an independently
trained physical twin. Consequently, its realized NLL, NEES, and endpoint error
are diagnostics and must not be reported as calibrated provider performance.

## Arms and primary decision

The run evaluates:

1. full shared covariance;
2. posterior-preserving compression with maximum rank three;
3. equal-rank observation-covariance PCA;
4. conditional-only uncertainty; and
5. a cached full query gain/covariance reference.

A successful diagnostic requires at least one safely parsed real trajectory and
reports full-versus-compressed gain, posterior covariance, and realized posterior
mean parity. A rank-cap failure returns the exact original factor rather than an
inexact truncation. PCA and conditional-only arms are failure controls, not
registered competitors for provider promotion.

Archive records are not asserted to be independent physical objects, so the v1
study reports distributions and worst cases without archive-level p-values.

## Reproduction

```bash
PYTHONPATH=src python3 \
  scripts/science/run_pokeflex_posterior_compression_real_geometry.py \
  --dataset-root /mnt/lexar4tb/pokeflex \
  --protocol protocols/pokeflex-posterior-compression-real-geometry-v1.json \
  --output-dir outputs/pokeflex-posterior-compression-real-geometry-v1 \
  --source-revision "$(git rev-parse HEAD)"
```

The self-hosted workflow uses labels `self-hosted` and `gpuserver4090`, performs a
hosted syntax/test preflight first, checks out the exact push SHA without persisted
credentials, uses no repository secrets, and uploads only compact JSON/Markdown
evidence. If the reported path is not mounted on the selected runner, the retained
decision is `dataset-root-missing`; it is not relabeled as a scientific negative.

## Claim boundary

A positive result establishes that the local numerical kernel can preserve one
fixed physical-query posterior on selected real PokeFlex geometry while reducing
the corresponding shared factor. It does not establish PokeFlex release
completeness, a useful real 4D provider, real covariance calibration,
BayesianPhysTwin physical benefit, Causal4D intervention benefit, object-level
generalization, deployment safety, or state of the art.
