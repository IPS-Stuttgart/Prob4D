# Added

- Add experimental Proof4D local certificates binding an observable-gauge factor to one declared linear query, its assumptions, provenance, and exact caller-owned fallback.
- Add global axial-orbit action certificates that analytically prove robust fallback-minus-candidate advantage over every angle in a declared continuous ambiguity arc rather than sampling the orbit or trusting a local derivative.
- Bind global action authorization to the shared gauge geometry, support receipt, both action-loss program digests, admission-policy digest, sealed input, exact fallback belief digest, assumptions, and optional calibration receipt.
- Add independent, fail-closed module verifiers that recompute content IDs, local subspace witnesses, global harmonic differences, complete-arc extrema, producer decisions, and reason codes without importing the producing Prob4D modules.
- Add caller-owned, content-addressed execution contexts that prevent an internally valid certificate from being replayed for a different input, factor, query, action, support receipt, policy, or fallback.
- Require certificate-plus-context verification for execution authorization; standalone certificate verification remains a diagnostic and cannot by itself authorize the current transaction.
- Distinguish valid admission, valid consequence rejection, and invalid-certificate or context rejection so malformed or mismatched evidence can never authorize factor or action consumption.
- Add immutable admitted/rejected examples and adversarial tests for content tampering, false admission, malformed subspaces or orbits, altered extrema, missing support receipts, widened claim scope, duplicate JSON keys, cross-context replay, and non-overwriting publication.
- Keep the installed console-script surface unchanged; independent Proof4D verification is available through `python -m prob4d_independent_verifier.proof_carrying`, `python -m prob4d_independent_verifier.orbit_advantage`, and `python -m prob4d_independent_verifier.execution_gate`.
