# PointWorld--Flat'n'Fold branch progress

This branch is additive and experimental. It does not change the claim-bearing
dense provider, production gauge tree, BayesianPhysTwin update, or Causal4D
protocol.

Implemented:

- source-only study and representation protocols;
- immutable versioned sparse persistent-point prediction windows;
- canonical content identities and strict no-clobber NPZ persistence;
- dependency-light PointWorld source export and converter;
- explicit retention of uncalibrated native PointWorld log variance;
- outcome-blind three-camera Flat'n'Fold support inventory conversion into
  `ProviderSupportFeasibilityV1`;
- a committed replayable synthetic inventory example;
- adversarial schema, identity, dtype, mask, lineage, no-clobber, support-negative,
  and information-boundary tests; and
- a focused GitHub Actions validation lane.

Not yet executed:

- exact PointWorld checkpoint/runtime byte freeze;
- Flat'n'Fold dataset-byte and complete garment-roster freeze;
- Baxter/gripper action-to-robot-point-flow conversion;
- one real source-only PointWorld sparse export;
- source mean/identity competence;
- native uncertainty calibration and dependence modelling;
- cross-window sparse association/fusion;
- held-out garment provider evaluation;
- BayesianPhysTwin query evaluation; or
- any Causal4D evaluation.
